# Online Retail 数据集来源

英国某线上礼品零售商的真实交易流水（同一零售商两个时间段），本项目的主数据集。
列名为标准英文（InvoiceNo / StockCode / Description / Quantity / InvoiceDate /
UnitPrice / CustomerID / Country），进入分析时 8 个字段全部自动映射。

| 文件 | 行数 | 时间范围 | 说明 |
|---|---|---|---|
| `Online Retail.csv` | 541,909 | 2010-12 ~ 2011-12 | 主数据集 |
| `Online Retail.xlsx` | 541,909 | 同上 | 同数据的 Excel 格式（用于演示 .xlsx 导入） |
| `Online Retail II.csv` | 525,461 | 2009-12 ~ 2010-12 | 跨数据集验证用（仅取 2009-2010 部分，与主集不重复） |
| `online_retail_II.xlsx` | 525,461 | 同上 | 同数据的 Excel 格式 |

## 来源（确定）
- Online Retail：UCI Machine Learning Repository, Dataset #352
  https://archive.ics.uci.edu/dataset/352/online+retail
- Online Retail II：UCI Machine Learning Repository, Dataset #502
  https://archive.ics.uci.edu/dataset/502/online+retail+ii

两套来自同一零售商，合计覆盖其 2009–2011 全周期。
